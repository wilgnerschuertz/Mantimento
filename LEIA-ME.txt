QWEN LOCAL — primeira versão para Mac Apple Silicon (macOS 14+)

Abra “Qwen Local.app”. O aplicativo possui uma janela nativa, sem Electron.

COMO USAR
1. Preparar: baixa Python 3.12 e instala MLX em ambiente isolado.
2. Baixar modelo: baixa mlx-community/Qwen3.5-9B-4bit (vários GB).
3. Iniciar: inicia o servidor MLX; o primeiro pedido carrega o modelo.
4. Digite sua mensagem e clique em Enviar (ou Command + Return).
5. Parar / liberar RAM encerra o servidor, inclusive uma geração em andamento.
Preparar e Baixar exigem internet. Iniciar força modo offline.
O chat mostra a resposta aos poucos (streaming), com cópia de mensagens e blocos de código.

Nesta máquina o ambiente foi preparado durante a criação. Consulte
VALIDACAO.txt para o resultado final dos testes e do download.

ARMAZENAMENTO
Ambiente, modelo e histórico ficam em:
~/Library/Application Support/QwenLocal/
Conversas são salvas em conversations.json e aparecem na barra lateral.
O histórico anterior é importado automaticamente. Nova conversa preserva as anteriores.
Exportar conversa salva uma cópia em texto no local escolhido.
O aplicativo pode ser movido para Aplicativos; os dados continuam no mesmo lugar.

API PARA AGENTES
Enquanto o servidor estiver ativo, a API compatível com OpenAI fica em:
http://127.0.0.1:12345/v1
Modelo: default_model
Não requer chave. Apenas a interface de loopback é usada.
O aplicativo inclui agente de arquivos e terminal. Chamadas de ferramentas
foram testadas com o Qwen3.5 9B. Integrações com agentes externos não foram testadas.

LIMITES
O tamanho pequeno da interface não diminui os pesos do Qwen. O modelo e sua
memória de execução continuam ocupando vários GB. Não houve comparação de
RAM ou velocidade com LM Studio. Não configure contextos enormes nos agentes.
O chat limita o histórico a aproximadamente 16 mil caracteres e cada resposta
a 2048 tokens por padrão (ajustável de 1024 a 4096) para moderar o consumo. O limite em caracteres não equivale a um
limite exato de tokens. A API permite que clientes externos usem outros limites.
O chat processa texto; o agente consulta texto UTF-8 e PDF textual na pasta
de trabalho. Sem OCR, voz, imagens, edição Word ou planilhas nesta versão.
Não há assinatura Developer ID nem notarização Apple; há assinatura ad hoc local.

CÓDIGO-FONTE
source/App.swift — janela e cliente HTTP.
source/runtime.sh — ambiente, download e servidor MLX.
source/build.sh — recompila e assina localmente o aplicativo.
Execute bash source/build.sh para recompilar (requer ferramentas Apple).

MODELOS E CONFIGURAÇÕES (versão 0.2)
Abra Configurações para selecionar o modelo. Para adicionar outro, informe
organização/modelo do Hugging Face, clique Adicionar, depois Baixar modelo.
Para arquivos já baixados, use Escolher pasta e selecione a pasta completa
MLX, incluindo config, tokenizer e pesos. Desligue o modelo antes de trocar.
Cadastrar não valida compatibilidade: o motor MLX instalado deve suportar a
arquitetura. GGUF não é suportado. Só o Qwen3.5 9B foi validado nesta máquina.
A seleção de modelo é lembrada entre aberturas; os controles de temperatura
e limite de resposta voltam aos padrões ao reabrir.
Ao interromper uma geração, o servidor é desligado para liberar memória.

AGENTE LOCAL — versão 0.3
Cada conversa tem uma pasta própria em Workspaces nos dados do aplicativo.
Use Mudar pasta para escolher uma pasta existente. A escolha acompanha a
conversa. Ative Agente de arquivos e terminal para usar as ferramentas.
Modo padrão: leituras automáticas, revisão antes/depois de escritas e aprovação
antes de executar comandos. Controle total dispensa essas aprovações.
O modo volta a revisão ao trocar de conversa e ao reabrir o aplicativo.
Ferramentas de arquivo ficam na pasta e rejeitam links simbólicos. O terminal
não é uma sandbox: comandos têm as permissões do seu usuário, inclusive fora
da pasta escolhida. Não existe controle visual de outros aplicativos.
Versões anteriores de arquivos editados por write_file ficam em .qwen-backups.
Alterações feitas pelo terminal não passam por esse backup de arquivo.
O chat registra resultados das ferramentas; o histórico atual não reproduz
comandos automaticamente ao reabrir. O agente usa no máximo 12 etapas por pedido.
Comandos são tarefas finitas, com timeout de 60 s e saída capturada limitada;
processos do grupo são encerrados ao terminar/interromper. Não inicie servidores
persistentes pelo agente nesta versão. Downloads/instalação de dependências
não disponíveis continuam exigindo rede. A inferência permanece local.
Busca literal: até 120 arquivos por busca, inventário até 500. Leitura de PDF
limitada a 40 páginas/16 mil caracteres; texto até 16 mil caracteres. Não há
índice semântico. Documentos maiores podem ser truncados.

GIT DO APLICATIVO
O diretório QwenLocal contém um repositório Git local com fonte e testes.
O .app compilado e os dados/modelos do usuário não são versionados.
Não foi criado repositório remoto nem publicado código.
Pastas de trabalho não são automaticamente versionadas. Para versionar um
projeto criado pelo agente, peça git init e revise os arquivos antes do commit.

VERSÃO 0.4 — INTERFACE DO MAC
Modelos e ajustes agora abrem uma janela separada na barra lateral.
O menu da pasta oferece Mudar pasta, Abrir no Finder e Copiar caminho.
Conversa/Agente ficam no seletor superior. As ações do agente aparecem recolhidas
no chat. Acompanhar resposta pode ser desmarcado para ler durante a geração.
O chat exibe tempo até o primeiro texto e tempo total ao concluir a resposta.
Streaming agrupado a cada ~100 ms e mensagens antigas não reprocessadas quando
inalteradas. Documentos são lidos/pesquisados fora da fila principal da interface.
